# Project AGENTS Rules

## Java 初学者（前端背景）代码生成与讲解规范
- **用户背景**：用户是 Java 初学者，此前具备前端开发背景。
- **响应要求**：每次生成、修改或重构 Java 代码（包括 Spring Boot、MyBatis-Plus、Maven 配置等）时，必须提供极尽可能详细的中文说明与逐行/逐块功能分解。
- **概念类比**：在解释 Java 语法、Spring Boot 注解、类设计和 Maven 依赖时，积极联系前端已知技术栈（如 TypeScript, npm, Express/Fastify, Prisma/TypeORM）做直观映射对比，帮助用户迅速建立技术认知。

## 1. 根目录文件夹功能详解

资源管理器根目录下的所有文件夹具体职责与作用如下：

| 文件夹名称 | 作用与用途详解 | 前端技术栈直观类比 |

## 3. src 源码目录核心分层解剖

`src` 目录是后端开发的核心，结构如下：

```text
src
└── main
    ├── java/com/zqw/crm              ──► Java 后端代码根包
    │   ├── CrmApplication.java       ──► 🚀 Spring Boot 项目唯一的启动类（主程序入口）
    │   ├── controller/               ──► 路由控制层 (类似 Express Controller/Router)
    │   ├── service/ & impl/          ──► 业务逻辑层 (处理复杂业务计算与事务)
    │   ├── mapper/                   ──► 数据持久层 (类似 Prisma Client，直接查数据库)
    │   ├── entity/                   ──► 数据库表映射实体 (类似 TypeORM Entity)
    │   ├── vo/                       ──► 接口入参和出参模型 (类似 TS Interface)
    │   ├── security/                 ──► 登录拦截与 JWT 权限验证 (类似路由守卫中间件)
    │   └── common/                   ──► 全局统一响应格式 Result 与全局异常处理
    └── resources
        └── application.yml           ──► ⚙️ 后端全局配置文件（配置数据库连接、端口、密码）
```

## 4. 面向前端转 Java 者的概念对照表

| 前端 (Node/TS/React) 概念 | Spring Boot / Java 对应概念 | 本项目中的包/文件 | 核心职责说明 |
|---|---|---|---|
| **`Express/Koa Router`** (路由处理器) | **`Controller` 控制层** (`@RestController`) | `com.zqw.crm.controller` | 监听 HTTP 请求，定义 API 路由，校验参数并返回 JSON。 |
| **`TypeScript Interface / Zod DTO`** | **`VO` / `Req/Resp`** | `com.zqw.crm.vo` | 定义前端输入的 JSON 格式及后端响应的字段结构。 |
| **`Prisma / TypeORM Model`** | **`Entity` 实体类** (`@TableName`) | `com.zqw.crm.entity` | 1 对 1 映射 MySQL 数据库中表的字段结构。 |
| **`Prisma Client (findMany/create)`** | **`Mapper` 持久层接口** (`BaseMapper<T>`) | `com.zqw.crm.mapper` | 执行增删改查 SQL，MyBatis-Plus 自动提供单表 CRUD 方法。 |
| **`Express Middleware` 中间件** | **`Filter` 过滤器 / `SecurityConfig`** | `com.zqw.crm.security` | 请求到达路由前，拦截校验 JWT Token 的合法性与提取当前用户。 |
| **`app.use((err, req, ...))`** | **`GlobalExceptionHandler` 全局异常捕获** | `com.zqw.crm.common` | 统一拦截捕获系统异常，返回优雅的 JSON 错误信息。 |
| **`package.json` + `npm`** | **`pom.xml` + `Maven`** | `pom.xml` | 声明项目的外部依赖库（Jar 包）和打包配置。 |

## 2. IDE 报错（Duplicate Method 重复方法）排查与修复

### 🐛 报错现象
编辑器在 `Result.java` 等实体/响应类中提示红线错误：`Duplicate method Result() in type Result<T>`。

### 🔍 根因分析
1. 类上面使用了 Lombok 注解（`@Data`, `@NoArgsConstructor`, `@AllArgsConstructor`）；
2. 类内部同时手动编写了 `public Result() {}` 和 `public Result(code, msg, data) {}` 等构造函数以及 Getter/Setter；
3. Lombok 编译期生成的方法与手写方法的方法签名**完全重合**，导致 IDE 和 Java 编译器检测到重复方法签名冲突。

### 🛠️ 解决方案
重新规范代码结构：删除了冗余的冲突 Lombok 注解，为数据传输对象与响应实体提供了规范的标准 Java 构造函数和 Getter/Setter。重新编译验证 `mvn clean compile` 后，构建成功且编辑器报错线完全消除。

## 3. Maven (mvn) 作用与常用指令详解

`mvn` 是 **Apache Maven** 命令行工具的简称，是 Java 生态中最主流的 **自动化构建与依赖管理工具**。

### 核心功能
1. **依赖自动化管理**：只需在 `pom.xml` 中指定所需依赖及版本，Maven 就会自动从远程仓库下载并配置。
2. **构建生命周期管理**：自动处理编译、打包、测试、运行全流程。

### 常用命令清单

| 命令 | 实际作用 |
|---|---|
| `mvn clean` | 清理上一次构建产生的 `target` 目录 |
| `mvn compile` | 编译主源代码 (`src/main/java`) 生成 `.class` 字节码 |
| `mvn clean compile` | 先清理旧输出，再全量重新编译项目 |
| `mvn test` | 运行项目中的单元测试 |
| `mvn package` | 将项目编译打包成二进制包（如 `.jar`） |
| `mvn spring-boot:run` | 启动 Spring Boot Web 应用程序 |

## 5. OpenAPI / Knife4j 接口文档生成原理

Knife4j / Swagger 接口文档的底层运行原理可分为以下 4 个阶段：

1. **反射扫描**：项目启动时，Spring 容器通过 Java 反射扫描带有 `@RestController` 的类、路由注解（`@PostMapping` 等）及描述注解（`@Tag`, `@Operation`）。
2. **生成 OpenAPI JSON 数据**：SpringDoc 框架解析得到的接口路径、请求体参数、响应体结构等元数据，生成符合 OpenAPI 3.0 规范的 JSON 文本流（发布在 `/v3/api-docs` 节点）。
3. **前端异步渲染**：在浏览器打开 `doc.html` 时，Knife4j 前端 SPA 页面拉取 `/v3/api-docs` 数据，将其渲染为包含分类菜单、参数表格的图形化界面。
4. **交互调试代理**：用户在网页上点击“发送”按钮时，前端网页直接向后端目标接口发起真实 HTTP 请求并呈显响应数据。
